\section{Experimental Methodology}
\subsection{Experimental Design}

Our experiments follow a rigorous methodology designed to ensure reliable and comparable results:

\begin{itemize}
    \item \textbf{Model Variants}: Evaluation across multiple YOLO architectures
    \item \textbf{Dataset Variants}: Testing on different classification granularities
    \item \textbf{Training Configuration}: 50 epochs, 5 inner folds, 5 outer folds, 20 Optuna trials
    \item \textbf{Hardware Setup}: Dual NVIDIA A100 GPU training with comprehensive resource monitoring
\end{itemize}

\subsection{Evaluation Metrics}

The primary evaluation metric is mAP50-95 (mean Average Precision at IoU thresholds 0.5 to 0.95), which provides a comprehensive assessment of detection accuracy across different precision requirements. This metric is particularly relevant for agricultural applications where precise object localization is crucial.

\subsection{Baseline Comparisons}

Our results are compared against the original CropAndWeed paper benchmarks, providing context for the improvements achieved through our methodological approach. The comparison focuses on identical model architectures (YOLOv5s and YOLOv8s) trained for the same number of epochs to ensure fair evaluation.
