\section{Developer Usage Guide}
\subsection{Basic Usage Workflow}

The conversion pipeline follows a simple two-step process:

\begin{enumerate}
    \item \textbf{Convert CSV to YOLO}: Transform annotations from CSV format to YOLO format
    \item \textbf{Create unified structure}: Organize files for machine learning pipeline
\end{enumerate}

Example command for Fine24 dataset:
\begin{lstlisting}[language=bash]
python csv_to_yolo.py --dataset Fine24 --output_dir ./output/labels_Fine24
python dataset_structure.py --dataset_name Fine24 --output_dir ./pipeline_dataset_Fine24
\end{lstlisting}

\subsection{Quality Assurance}

The pipeline includes comprehensive validation to ensure data integrity:
\begin{itemize}
    \item Image-label correspondence verification
    \item Coordinate validation within image boundaries
    \item Class consistency checking
    \item File integrity validation
\end{itemize}
